How It Works

1

Configure

Define your projects — repo, stack, deploy target, and category.

2

Scan

Canary fetches data from GitHub, npm, PyPI, and more via parallel scanners with circuit breakers.

3

Grade

A 100-point scoring algorithm grades each project A–F with context-aware adjustments.

4

Act

Get specific update commands, release notes, and recommendations — not just warnings.

Grading System

Context-aware scoring with leniency for maintenance and prototype projects.

A
90+ Healthy — no action needed
B
75–89 Good — minor improvements possible
C
60–74 Needs updates — falling behind
D
40–59 Needs upgrade — significant debt
F
0–39 Critical — consider rewrite
